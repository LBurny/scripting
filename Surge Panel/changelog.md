## 本次更新（2.0.6）

- 桌面小组件全新布局：速率大字号为主视觉（左下载 / 右上传对称排布），顶部实例名 + 状态点 + 出站模式徽章，底部新增分隔线与合计速率、更新时间
- 新增小尺寸（systemSmall）专用布局；连接失败改为居中错误提示与引导，不再显示 0 速率、空面板

## 上次更新（2.0.5）

- 性能：速率秒级刷新不再带动所有 Tab 整体重渲染，策略 / 请求 / 设置等长列表滑动更顺
- 性能：总览的事件、功能开关、Fake-IP 计数、本机地址改为 30 秒低频刷新，且仅总览可见时拉取，不再跟随每次采样
- 性能：采样历史改为每 30 秒落盘一次（离开或切实例时立即保存），减少高频写入
- 策略页不再每个周期拉整份配置解析组顺序：改为内存缓存，面板内重载配置自动失效，下拉刷新强制重取
- 规则页改为进入时加载 + 下拉刷新，不再随周期轮询整份规则
- 活动连接详情页跟随刷新：实时速率与流量持续更新，连接结束会标记「已结束」
- 最近请求增加「仅失败 / 仅拒绝」筛选
- 设置「历史长度」的时长说明与刷新间隔联动；内存趋势「数据不足」提示按实际采样间隔计算
- 请求 Tab 可见时总览不再重复拉取最近请求；缩短历史长度立即生效

## 更早（2.0.4）

- 总览活动连接的失败 / 拒绝改回与其它卡片同一行高度，有数据时替代「HTTP 请求」
- 点按活动连接、DNS、实时下载 / 上传分别跳到请求与流量对应页，不额外加点击提示

## 更早（2.0.3）

- 总览活动连接的失败 / 拒绝改到数字下方单独一行，不再和「HTTP 请求」挤在一起被裁切
- 内存诊断的变化速率改为近 20 分钟回归斜率，并增加全程振幅；长窗口首尾相减不再显示成 -0.0
- 策略组列表显示当前节点测速延迟；组内「最优」与延迟同时显示，未测速的节点标「未测速」

## 更早（2.0.2）

- 流量页增加「本次运行分流」：按直连 / 代理累计体积与占比
- 网卡副标题显示易读名称（回环、蜂窝、Wi-Fi 等），主标题仍是系统接口名
- 总览活动连接徽章同时显示近期失败与拒绝数
- DNS 卡片副标题显示 Fake-IP 占用（从缓存记录的地址计数）
- 能读到本机地址时，总览与设置实例脚注会带上主 IPv4 / IPv6（脚本未开则静默）
- Key 无效、连接超时时给出更短的中文说明，仍提示到「设置 → 实例」检查
- 设置里的模块改到子页开关，并用系统搜索栏筛选，避免模块很多时把引擎区拉得很长
- 当前配置先列出分段再进入详情，长配置不再一次渲染整页，滑动更顺
- 总览点按地址可隐藏实例与本机 IP（设置里也可开关），方便截图分享

## 更早（2.0.1）

- 首次安装不再自动创建「本机」并立刻连接；总览引导添加实例，避免一进来就报 TLS / 未授权错误
- HTTPS 请求跳过 Surge MITM 自签证书的系统链校验（鉴权仍靠 X-Key）；默认协议改为 http，对齐 `http-api-tls = false`
- 添加或保存有效实例后才会开始轮询；未填写 Key 的实例不会去连
- 商店版 iOS 与 Mac 6.8 没有 `/metrics`：总览不再因此报连接失败。时长 / 活动连接 / DNS 改走 HTTP API；内存与封禁需 iOS 5.22+ 或 Mac 6.9+（TestFlight）
- DNS 静态 Host 的 `data` 可能是字符串而非数组，列表与详情不再因此渲染失败

## 更早（2.0.0）

- 支持多个 Surge HTTP API 实例：总览点名称切换，设置里添加 / 编辑 / 测试连通 / 删除；热切换不重开面板
- 采样历史按实例分开存放，旧的单组连接会自动迁成「本机」
- 总览增加 MitM / 捕获 / 重写 / 脚本快捷开关
- 活动 / 最近请求支持搜索与排序；DNS 同时展示静态 Host 与动态缓存
- 流量明细可按实时 / 累计 / 峰值排序
- 脚本页增加调试执行（`/v1/scripting/evaluate`）
- 当前配置可选择显示敏感字段；策略组内嵌套组可再点进
- 当前可见 Tab 按面板间隔自动刷新
