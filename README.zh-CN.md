## 🚀 快速开始

1. 从 App Store 安装 **Scripting** App。
2. Clone 或下载本仓库。
3. 将需要的项目拷贝到 Scripting 的文档目录（iCloud 中的 `Scripting/` 文件夹）。
4. 在 App 中打开项目并运行。
